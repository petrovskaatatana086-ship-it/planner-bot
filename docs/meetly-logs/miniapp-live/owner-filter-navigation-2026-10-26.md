# Переход к отфильтрованным заявкам

Пользователь сообщил: после нажатия «Ожидают» владельцу приходится прокручивать
страницу вниз в поиске списка. Фильтр обновлял содержимое, но не позицию экрана.

В live.js после загрузки фильтра фокус и прокрутка переходят к панели заявок.
Это применяется ко всем четырём счётчикам. Выбранный фильтр выделен и получает
aria-pressed. При конкурирующем переходе устаревший запрос не меняет прокрутку.
При ошибке загрузки переход не выполняется. Пагинация начинается заново.

Коммит: 3eab6ee94a5afd331006e9f92fa5c2488293c4ac.
Проверены node --check и git diff --check. Полный backend-регресс не повторялся:
изменён только клиентский переход после фильтрации.
Проверка на телефоне пользователем пока ожидается.
