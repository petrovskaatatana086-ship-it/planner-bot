# Местное время клиента в Mini App

Часовой пояс клиента определяется через Intl из настроек устройства. В календаре,
слотах, карточках, переносе и подтверждении показываются местные даты и время.
Рядом отображается разница с Москвой, например «МСК +3 ч»; при совпадении — «МСК».
Разница вычисляется на дату встречи, включая сезонные и получасовые смещения.
У администратора всё остаётся в Europe/Moscow.

API возвращает исходные моменты времени; отправка команды сохраняет исходный
start_at. Для клиентского календаря запрашиваются московские дни с запасом по краям,
затем слоты группируются по местной дате начала. Диапазоны API не превышают 31 день.
Слоты выбранного дня проверяются повторным запросом. Расписание и рабочие дни
специалиста по-прежнему определяются по Москве.
