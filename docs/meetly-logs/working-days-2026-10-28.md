# Рабочие дни в настройках администратора

В рабочем Mini App добавлены семь переключателей Пн–Вс. Неотмеченные дни
закрыты для новых записей и переносов через общий слой доступности и команд.
Можно закрыть всю неделю. Существующие встречи не изменяются.

Используется существующая таблица ScheduleRule; миграция не требуется.
При отсутствии правил сохраняется прежний график Пн–Пт, 10:00–18:00 по Москве.
Настройка сохраняется атомарно с версией профиля, проверкой прав и защитой повтора.
У существующих правил сохраняются интервалы часов; для новых дней — 10:00–18:00.

Время интерфейса сейчас фиксировано в Europe/Moscow для всех пользователей.
Автоматического перевода в часовой пояс клиента этим изменением не добавлено.
