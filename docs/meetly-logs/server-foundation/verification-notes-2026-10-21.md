# Серверная основа — 21.10.2026

Изменения: UTC Interval; SQLite BEGIN IMMEDIATE runner; FK/busy_timeout; version/уникальность Meeting; migration 0006; operation_results/outbox; локальные команды create/approve.

Проверено:
- Две независимые engine одного файла: пересекающиеся интервалы имеют одного победителя; повтор одного ключа создаёт одну заявку и один комплект заданий.
- Конкурентное одобрение создаёт одну встречу, устаревшая версия получает конфликт.
- Replay после commit/через другой сервис не создаёт повторов; другой payload и blocked actor отклоняются.
- Отмена задачи и ошибка откатывают write; SQLITE_BUSY исчерпывается/восстанавливается.
- Резервы на точной границе expiry, лимит, частичное пересечение, buffer и часовая сетка.
- Миграция выполняет настоящие Alembic Operations для 0001–0006 на синтетическом файле; сохраняет данные и останавливается до DDL при duplicate/invalid/orphan/partial proposal.
- Полный unittest: 90 тестов OK, лог full-tests-2026-10-21.txt. Исходные warnings aiohttp AppKey остаются; это не падения.

Не проверено/не реализовано: переключение действующего бота на новый сервис, HTTP/auth, новые Google операции, outbox delivery, structured reschedule/calendar_sync, live-миграция, телефон/Telegram UI. Тесты новых команд не читают .env и не отправляют сообщения. Для Google настроенного профиля команды fail closed до подключения внешней проверки. Worker пока отсутствует, новые команды не exposed.

Для существующей dev-БД перед запуском новой версии требуется Alembic upgrade head после резервной копии. create_all не добавляет version в существующие таблицы. Production не изменяется этим локальным результатом.
