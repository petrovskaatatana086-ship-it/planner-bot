# Встречи администратора без Google Calendar

По скриншоту пользователя выявлена оставшаяся заглушка в административном
разделе «Мои встречи». Предыдущая правка добавила кнопки только клиенту.

Администратор теперь получает до 20 предстоящих встреч из локальной базы,
с датой по Москве, названием и русским статусом. Google для списка не нужен.
Будущие активные встречи получают кнопки переноса и отмены. Перенос владельцем
выполняется напрямую через общую reschedule_by_owner; запрос клиента по-прежнему
требует решения. Pending-предложение при прямом переносе владельцем закрывается
общей командой. Отмена требует подтверждения, повтор callback идемпотентен.

Права проверяются по настроенному Telegram ID владельца и активному статусу.
Клиент не может использовать owner callback или подменить действие формы.
Карточка и форма сохраняют версию встречи. Выход возвращает меню своей роли.
При отключённом runtime кнопки изменений отсутствуют. Старая карточка в Telegram
не обновится автоматически: после выкладки необходимо снова нажать «Мои встречи».
