# Копии email администратору основного бота

По запросу пользователя включены скрытые копии клиентских email-уведомлений
на согласованный Gmail администратора. Адрес задаётся SMTP_ADMIN_COPY_EMAIL;
пустое значение отключает копии. Получатель добавляется через Bcc в SMTP envelope,
SMTP.send_message убирает заголовок Bcc из передаваемого письма. Если адрес уже
есть в To/Cc/Bcc, повторного получателя не добавляем (без учёта регистра).

Общий адаптер охватывает legacy-уведомления и SMTP outbox. Копии отправляются
только вместе с существующими клиентскими письмами; новых типов писем не добавлено.
В production SMTP ранее был выключен. Подключён проверенный Gmail, который уже
используется тестовым ботом. Секреты не включены в отчёты или Git.
