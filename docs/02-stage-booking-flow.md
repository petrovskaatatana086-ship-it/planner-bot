# Этап 2. Сценарий записи и заявки

## Цель

Сделать основной пользовательский сценарий записи без Google: клиент создает заявку, владелец видит ее и принимает решение.

## Что реализуется

- черновик заявки;
- выбор даты;
- выбор времени;
- правило записи минимум за 24 часа;
- рабочие дни и базовое рабочее время;
- ввод названия встречи;
- ввод комментария;
- итоговая проверка заявки;
- отправка заявки владельцу;
- список заявок клиента;
- список встреч клиента;
- список новых заявок для владельца;
- подтверждение заявки владельцем;
- отклонение заявки с причиной;
- создание встречи после подтверждения.

## Основные файлы

- `app/domain/booking.py` - логика дат, слотов и названия встречи;
- `app/db/models.py` - модели заявок, черновиков и встреч;
- `app/db/repositories.py` - операции с заявками;
- `app/bot/handlers.py` - Telegram-flow записи;
- `tests/test_booking.py` - тесты доменной логики записи.

## Сущности БД

- `BookingDraft`;
- `BookingRequest`;
- `Meeting`;
- `ScheduleRule`.

## Как проверить вручную

1. Запустить бота:

```powershell
python -m app.main
```

2. Клиент проходит `/start` и регистрацию.
3. Клиент нажимает «Записаться на встречу».
4. Клиент выбирает дату из списка.
5. Клиент выбирает время.
6. Клиент вводит название встречи.
7. Клиент вводит комментарий или «Без комментария».
8. Клиент отправляет «Отправить заявку».
9. Владелец получает уведомление.
10. Владелец открывает «Новые заявки».
11. Владелец отправляет `Подтвердить 1` или `Отклонить 1`.

## Техническая проверка

```powershell
python -m unittest discover -s tests
python -c "import app.main; print('app import ok')"
python -m compileall app tests
```

## Признаки успешного завершения

- клиент может создать заявку;
- недоступные слоты не показываются;
- заявка появляется у владельца;
- подтверждение создает встречу;
- отклонение сохраняет причину;
- клиент видит свои заявки и встречи;
- тесты проходят.

## Что не входит

- Google OAuth;
- создание события Google Calendar;
- создание ссылки Google Meet;
- email-приглашения;
- переносы и отмены;
- полноценное управление расписанием;
- мониторинг и резервные копии.
