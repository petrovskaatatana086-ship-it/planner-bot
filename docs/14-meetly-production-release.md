## Порядок продолжения

1. Проверить завершение OAuth, обновить snapshot и повторить legacy inspect.
2. Убедиться в успешном полном регрессе и nginx snippet
   deploy/miniapp.production.nginx.conf; будущий URL `/meetly/`, API `/api/meetly/v1/`.
3. Взять deploy.lock; сохранить .env, compose, nginx, deploy state и предыдущее меню.
4. Остановить только основной bot; согласованный snapshot БД и integrity_check.
5. Upgrade head в новом образе на основной БД; проверить сохранность исходных строк.
6. Повторно inspect/adopt существующего Google-события с environment
   meetly-production: только private metadata, без изменения времени/участников,
   без приглашений и с сохранением существующего event ID.
7. Включить BOOKING_RUNTIME_ENABLED, CALENDAR_ENVIRONMENT=meetly-production,
   MINIAPP_ENABLED, MINIAPP_ORIGIN в private production env. Сохранить Gmail,
   SMTP_ADMIN_COPY_EMAIL, Google credentials и webhook-конфигурацию.
8. Запустить только основной контейнер. Health, HTTPS static 200, API без сессии
   401/no-store, чтение owner/client через подписанные тестовые сессии без мутаций.
9. Добавить только новые nginx locations, nginx -t/reload, проверить старые маршруты
   и неизменность тестового контейнера/соседних сервисов.
10. Установить и прочитать обратно кнопку «Открыть Meetly» основного бота.
    Зафиксировать image/source revision в deploy state и отчёте.

## Откат

До adoption не менять Google-события. После сохранения adoption intent нельзя
слепо восстанавливать старую БД: Google metadata могли уже измениться.
При сбое сохранить intent и логи для сверки. Старые данные нельзя восстанавливать
с потерей принятых после запуска команд. Для отключения Mini App убрать его
locations, вернуть прежнее меню и установить MINIAPP_ENABLED=false, сохранив
совместимый новый образ и booking runtime. Прежний образ нельзя запускать
стандартной командой после миграции: его Alembic не знает revision 0012.
Совместимость старого ORM сама по себе недостаточна.
При неясном результате adoption возобновление writers требует отдельной сверки.
